# Reborn Launcher 0.1.0

Initial release for the `x64-dx9-vanilla` channel.

## Included

- Guided exact-revision server source installation
- Docker Desktop, Podman Desktop, and Rancher Desktop backends
- Generated instance secrets and Compose override
- Server initialize, start, stop, status, and log controls
- Embedded regular plus God client torrent
- Client connection configuration and launch controls
- Atomic source staging and resumable torrent downloads
- Clean client payload audit and independent MonoTorrent verification
